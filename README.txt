DOLPHIN RICE WEBSITE
====================

Files:
- index.html  : page structure and content
- styles.css  : theme, responsive layout, hover states and animations
- script.js   : mobile menu, scroll progress, reveal effects, active nav,
                interactive export map, animated counters, back-to-top

Run:
1. Keep all three files in the same folder.
2. Open index.html in a browser, or use VS Code + Live Server.
3. Internet connection is required for Google Fonts and remote Unsplash images.
